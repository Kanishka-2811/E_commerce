# 🛒 Vortex Smart - Full-Stack E-Commerce Application

A modern full-stack e-commerce web application built to browse tech and lifestyle products dynamically from a secure database.

---

## 🚀 Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
* **Backend:** Spring Boot (Java), REST APIs, CORS Configuration
* **Database:** MySQL, Hibernate / JPA
